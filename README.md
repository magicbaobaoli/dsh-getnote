# dsh-getnote — 把「得到大脑」接进 DeepSeek Harness

左侧栏一个入口，中央一块面板。既**直接操作得到大脑（原 Get笔记 / biji.com）的云端内容**（看、改、删、打标签、语义召回、生成分享链接），
也把一切**镜像成本地 Markdown 文件**（离线可读、可搜索、可以用 `@路径` 喂给对话）。

自动同步默认需要你亲手开一次，开了之后就不用再管：只要 DSH 开着，它自己按时拉新笔记。

**本地优先**：笔记是磁盘上的纯 Markdown，会员到期之后，已经同步下来的内容照常能读能写能搜。
云端的 OAuth 登录和 API Key 都是**可选**增强。

## 两条通道，用哪条取决于你有什么

| 通道 | 你需要做的事 | 说明 |
| --- | --- | --- |
| **登录得到大脑**（OAuth） | 在「设置 → 自动同步」里点一次「登录得到大脑」，浏览器授权 | 一次授权，之后自动续期。**推荐**，不用去控制台 |
| **API Key**（官方 Open API） | 去 [openapi.biji.com](https://openapi.biji.com) 控制台建个人应用，拿 API Key + Client ID，填进「设置 → 云端接入」 | 长期凭证，不依赖浏览器 |

面板会自动挑：配了 Key 就优先用 Key，Key 被服务端拒绝（`401 / 未授权`）就**静默回落到登录通道**，
并在设置页用黄色横幅告诉你「Key 被拒了，现在走的是登录通道」——不会让你看到「已接入」却满屏报错。
换 Key 或清凭证会重置这个判断，重新试。

配额：官方 Open API 读 1000/天、写 200/天；登录通道实测宽得多。自动同步有增量模式，
连续两页没有变化就提前收工，不会把配额烧在读旧笔记上。

## 功能

**笔记（离线，完全不联网）**
- 目录树（按知识库/主题分）、标签云、全文搜索
- **左栏可整理**：目录与标签都能新建（标题行最右侧的「+」）、都能右键删除。
  右键后「删除」与「取消」**直接出现在被点的那一行里**（占据计数徽章的位置），
  不用去别处找按钮；点「删除」还会再弹一次确认框，再点「删除」才真删。
  目录非空时拒绝删除，会告诉你还剩几篇笔记——点一下垃圾桶就把几十篇送进回收站是灾难
- **三种排序，目录与标签各自独立**：按最近修改（默认，按目录/标签下最新一篇的时间算）、
  按名称、按条数。两个排序按钮各管各的，选择分别记在浏览器本地，下次打开还是它。
  分开的理由是它们用法不同——目录十来个、按名称找；标签几十个、按条数看热点，共用一个
  开关的话调标签顺序会把目录顺序一起改掉
- **标签改名**：右键标签行，那一行直接变成输入框，改完回车即可。做成行内而不是弹窗，
  是因为改名要边看原名边打字，弹窗会把标签云本身挡住。改到一个已存在的标签名时按
  **合并**处理（两边的笔记都归到新名字下，不会写出两个同名项）；改错了能靠版本历史退回。
  目录不提供改名——目录名就是磁盘上的文件夹名，改名等于移动文件
- **写作热力图**：左栏「全部笔记」正下方，最近 16 周的格子图，一眼看出有没有在坚持。
  完全离线算（日期本来就在文件名或 frontmatter 里），会员到期也照样画；五档色阶而不是
  连续渐变（7px 的格子放不下渐变）；未来日期画成虚线空框，免得被读成「那天写了 0 篇」；
  连续天数按「今天还没写不算断」算——很多人是晚上写，早上打开看到「0 天」会莫名其妙
- Markdown 阅读：标题、列表、任务列表、表格、引用、代码围栏、链接
- **待办勾选**：阅读笔记时正文里的 `- [ ]` 方框是可以直接点的，点一下落盘并重读，
  不用切到编辑模式去找那一行改字符。按「第几个待办」定位而不是按文本匹配——同一篇里
  常有两条一模一样的待办（「喝水」写了两遍），按文本改会一次改两行；代码围栏里的
  `- [ ]` 是示例代码，不参与编号也不会被改。每次勾选留一版版本历史，改错了能退回
- **自定义笔记模板**：内置日记 / 读书 / 会议 / 随手记四个，覆盖最常见的四类；但
  「周报」「复盘」「课程笔记」这种结构每个人都不同，硬编码进代码只会越堆越乱，所以
  设置页里可以自己攒，新建时直接出现在「+」菜单里。改完点一次保存整体提交（不是每改
  一项就发一次请求，否则删掉的那项会先闪一下再消失）；同名模板覆盖而不是并排两项——
  用户看到列表里有同名项，第一反应就是要改它
- **Obsidian 双链**：正文里的 `[[另一篇笔记]]` / `[[目标|显示文字]]` 是可点的，点了直接跳到那篇笔记；
  `![[图片.png]]` 会就地显示图片（按文件名在本文附件里找）
- **笔记头的「链」按钮**：在编辑与复制引用之间（图标是链子，复制引用是油漆刷——两个都画链子的话挨在一起分不清哪个是哪个）。
  点开是一个弹在最右栏居中、可按住拖走、点外面就收起的小窗，选中目标后自动在正文末尾追加
  `[[对方标题]]` 并重读，双链立刻可用。只连单向（反向关系图会自动画出来），已连过的不重复追加，
  写入走版本历史不留 `.bak`
- 编辑保存（不留 `.bak`：保存前的内容已经进版本历史，多留一份副本只会在库里堆看不见的垃圾）、
  新建（`YYYY-MM-DD-标题.md`）、删除进 `.trash/`
- **回收站页签**：删除的笔记能看见、能一键恢复（撞名时自动改名，绝不覆盖）、能永久清空
- 图片附件直接显示，不用切到文件管理器；播放器标题会自动去掉 `_<note_id>_audio` 这种机器后缀
- 「复制引用」把绝对路径复制成 `@path`，直接粘到对话里让 DSH 读

**云端（联网，直接操作得到大脑）**
- 笔记列表 + 分页加载
- **语义搜索**（官方 `recall`，按意思找，不是本地那个子串搜索）
- 打开一篇笔记看详情，录音笔记带**原始音频播放器**
- 改标题 / 改正文，保存即回写云端，并顺手刷新本地那份 `.md`
- **按知识库筛选**（顶上一排知识库 chip），**新建云端笔记**（可指定知识库）
- 加标签 / 点标签上的 `×` 删标签、创建分享链接（可排除音频）
- **把本地改动推回云端**：以前只能「云端 → 本地」单向，本地改完没法送回去；
  现在详情页有一个推送按钮（会二次确认，推的是正文与标题）

**音频**
- 录音笔记的音频地址在 `attachments[type=audio].url`（一个会过期的签名 URL），
  所以播放器不直连 CDN，而是走 `/getnote/audio?url=` 代理：签名不暴露给浏览器、
  支持 `Range` 请求（能拖进度条）、白名单限制域名（防止这个端点变成开放代理）
- **本地库里的录音也能直接播**：笔记同目录 `asset/` 下形如
  `<标题>_<note_id>_audio.mp3` 的附件，会显示成「本地录音」播放器，走
  `/getnote/asset?path=` 读磁盘（同样支持 Range）。认领靠 `note_id`，所以
  本地标题和云端标题不一样也能对上
- 进度条是自绘的（不是原生 `<input type=range>`）：整条轨道都是可点区域，
  点哪跳哪，按住拖动跟随，松手才真正 seek
- 逐字稿按「时间戳 + 说话人 + 内容」分条排版，中文长文自动折行，不是塞进等宽代码块

**读笔记更省事**
- **本文大纲**：打开一篇长笔记（录音转写那种几十段），阅读区顶部有一张可折叠的大纲卡，
  点哪一节就滚到哪一节。围栏代码块里的 `#` 不算标题，否则逐字稿里会冒出一堆点不动的假条目
- **关联笔记（反查双链）**：底部列出「哪些笔记引用了这一篇」，点了直接跳过去。
  匹配刻意放宽：完整路径、去扩展名的路径、文件名、标题，任一相等就算引用
- **搜索增强**：支持 `tag:标签`、`dir:目录`、`#标签` 限定，多个词是**取交集**（不是「或」），
  结果按「正文命中次数 + 标题命中」排序，每条笔记卡右侧显示命中次数，点开能看到带行号的命中片段
- **快捷新建模板**：「+」展开四种模板——日记 / 读书笔记 / 会议记录 / 随手记，
  预填日期与标签。日期按**本地时区**算，不是 UTC（否则晚上八点后新建会变成「明天」）

**改笔记更省事**
- **单篇推拉**：笔记头有两个按钮，一个把这一篇的本地改动推到云端，一个从云端拉最新版覆盖这一篇。
  只处理眼前这篇，不跑整轮同步（整轮要翻页扫全部笔记，很慢）
- **冲突比对**：云端和本地都改过时，同步会把两份都留下来。冲突页签左右并排列出
  「我的本地版」和「云端版」，一键采纳任一边。**哪一份是哪一份是按语义算的、不是按文件名猜的**：
  `.conflicts/` 里 `__<原名>` 的留档装的是本地版，`__cloud-<原名>` 的装的是云端版（早期手工
  抢救时存进去的），两种命名历史上并存过，混为一谈会让「用我的本地版」把云端内容写回正本。
  采纳前会先给当前正本存一份历史，不会丢内容
- **冲突页签常驻**：不管有没有待处理，页签一直在右边；只有未处理的数量挂在旁边当角标，
  处理一条减一，全处理完角标消失。处理过的收进「已处理」折叠区，随时能展开翻回去看、
  也能「退回未处理」
- **批量操作**：列表卡左上角有勾选框（悬停显形），选中若干篇后出现批量栏——
  批量加标签、批量移目录、批量移入回收站。移目录**保留原文件名**（日期前缀是归档约定，不丢）
- **版本历史**：每次保存/删除前自动留快照，每篇保留最近 10 版。笔记头的时钟按钮能翻历史、
  预览任意一版、一键恢复（恢复前会先把当前版本也存一版）

**数据可携带**
- **整库导出/导入 zip**：导出把整个库（笔记 + 附件 + 主题配置）打成一个 zip；
  导入默认「同名时另存一份」，也可以选「跳过同名」。ZIP 是自己实现的，文件名按 UTF-8 标记，
  中文名在 Windows 资源管理器里不会乱码
- **只在面板打开时同步**：自动同步的开关之一。开了之后，面板关着就不发请求、不烧配额

**用起来更顺手**
- **键盘快捷键**：`Ctrl/Cmd+K` 搜、`Ctrl/Cmd+N` 新建、`J`/`K` 上下翻笔记、`Esc` 退出输入
- **字号三档**：阅读区正文可以调小/标准/大三档，标题字号跟着等比缩放（不是只放大正文）
- **骨架屏**：首屏加载时显示三栏形状的占位，不是一片空白；系统开了「减少动态效果」时占位不闪
- **面板主题色**：设置里选一个颜色，左栏最深、中栏浅、右栏接近白——**只让你选色相，明度由代码锁死**，
  所以不管选什么颜色，三栏层次都不会乱。选色时整面板实时预览，点「应用」才保存
- **刷新键反馈**：点刷新会转三圈，成功变绿、失败变红，五秒后复原
- **再点一次就收起**：中栏里已经打开的那条笔记，再点一次就收起，右栏回到空白。
  笔记页与云端页都支持（只作用于列表卡片的点击——新建后自动打开、保存后刷新详情这些
  内部动作仍然是「打开」，在那里折起来是 bug 而不是功能）
- **深色模式**：设置页「主题色」卡里一个开关，切换立即生效并落盘。明度是按主题色算出来的
  （左栏最深、中栏次之、右栏最浅，栏间必须看得出层次），不是简单反色。
- **关系图配色**：同样在「主题色」卡里，默认是很浅的蓝 `#9dc6ef`。**只让你选一个颜色**，
  节点 / 连线 / 悬停高亮三个层次由代码推导，且连线永远比节点浅——连线是背景结构，
  节点才是内容，反过来整张图会变成一片网格。
- **应用内升级**：设置页最上面一张「检查版本更新」卡。读发布索引 → 比对版本 → 有新版就
  下载源码包、备份旧版、覆盖写回，提示重启 DSH。零依赖零构建所以这条路走得通（发布物就是
  `.js` 本身，不需要 install 也不需要编译）。**链接安装与 git 检出会被拒绝**（判据：目录是符号链接，
  或目录里有 `.git`）——覆盖等于冲掉未提交的改动。注意 Node 的 ESM 解析会先 resolve 符号链接，
  所以光比 `realpath` 判不出来，`.git` 那条是必需的；发布包里不含 `.git`，正常安装不受影响。
  升级前旧版整体备份到 `$DSH_HOME/dsh-getnote/update-backup/`；
  只写包里真实存在的文件、不删别的。断网单独识别成 `offline`，不会报成「升级失败」。
- **三种界面语言**：中文 / English / Nederlands，设置页一张「语言」卡就能切，切换即刻生效。
  「自动」跟随 DSH 自己的语言；选了具体语言就以那个为准，不会被宿主语言顶回去

**同步（自动或手动，在「设置」页里）**
- 同步不是独立页签，是「设置」页里的一张卡，紧跟「云端接入」——上面选通道、下面定频率。
- **自动同步**：开关 + 间隔（5 分钟 ~ 12 小时）。DSH 启动 20 秒后第一次跑，之后每分钟查一次
  「到点没有」，到点才真的发请求。失败静默（原因留在面板里），不刷错误提示
- 手动「立即同步」= 增量；「全量扫描」额外能发现**云端已删除**的笔记（慢、费配额，所以不自动）
- 增量同步遇到连续两页没变化就停，不全量扫
- 结果分列显示：拉取 / 保留本地 / 保留本地（接管）/ 冲突 / 移入回收站 / 失败

**导入（旧的一次性 OAuth 全量导入，仅在没有 API Key 时作为兜底出现）**

**设置**
- 笔记库目录可指定任意路径（默认 `$DSH_HOME/dsh-getnote/vault`）
- 空库时扫描常见位置并**建议**（不擅自切换）已有的归档目录
- 云端凭证状态、打码后的 Key、凭证文件路径
- **界面语言**：自动 / 中文 / English / Nederlands，存在 host 设置里（多开窗口、换机器都以它为准）

## 同步怎么决定「该不该动你的文件」

这是整个插件最容易毁数据的地方，规则写死如下——**一律偏向保住用户的东西**：

| 情况 | 行为 |
| --- | --- |
| 本地没有这篇 | 新建 |
| 本地有、且**没改过** | 覆盖成云端最新（不留 `.bak`，那份内容就是我们自己上轮写的） |
| 本地**改过**、云端没改 | 保留本地，只更新记账 |
| 两边都改 | 本地版另存 `.conflicts/`，正文写云端版，**备份失败就整篇不覆盖** |
| 本地已有 `note_id` 但同步引擎没见过它 | 判定为**你手写的**，原样保留并标记 `adopted`；以后云端再改也只往 `.conflicts/` 另存 |
| 云端删了、本地改过 | 保留本地，只在面板标「云端已删除」，不替你做主 |

写入前会先解析出真实的绝对路径（`resolveInside` 返回的是对象，不是字符串——这里踩过坑，
把它当字符串用会让每一篇都判成「本地不存在」从而无条件覆盖）。

## 界面

三栏是**从深到浅的同一条蓝**，越往里越亮，眼睛自然从「我在哪」滑到「我读什么」：

| 栏 | 配色 | 内容 |
| --- | --- | --- |
| 左 | 深蓝 `#0a2a52 → #071d3b` | 目录树、标签云，**一律白字** |
| 中 | 浅蓝 `#c5daf3 → #b6cfee` | 笔记列表，深蓝文字 |
| 右 | 近白蓝 `#f7fbff` | 阅读区 / 编辑区，深灰蓝正文 |

**深蓝填充上的字一律白**：左栏、右栏、以及云端/同步/冲突/设置四个整页，都显式写了
`--dsw-alias-label-primary-foreground`。漏掉这一行的话，主按钮、选中的 chip、选中的知识库
会落到应用默认的深色前景上——白底页面里看着还凑合，一旦填成深蓝就变成「深字压深底」，
几乎读不出来。

实现方式不是给每个元素改颜色，而是**在各栏容器上局部重定义 `--dsw-alias-*` 主题变量**：
自定义属性沿 DOM 继承，栏内所有用 token 的字色、底色、边框色自动跟着变。以后调色只改
一组变量，不会漏掉某个还在用旧 token 的角落。云端/同步/设置三个整页复用右栏那套浅色。

深色区的文字是**写死的白**（`#fff` / `.86` / `.66` 三档），不用主题色推导——推导出来的
浅色在换到墨绿、酒红主题时会偏成淡绿淡粉，反而不如白字干净。

**主题色**只让选一个色相，明度由代码锁死：左栏最深、中栏浅一档、右栏接近白，层次是
算出来的而不是让用户自己配。开放三个输入框的话，一旦有人填出「左栏比右栏还淡」的组合，
整个界面的空间感就散了。选色时整个面板实时预览，点「应用」才落盘。

扫描与列表会跳过 `.conflicts`、`.trash`、`.history`、`asset` 这些内部目录：前三个是不该
被当成笔记的副本、回收站与历史快照，`asset` 里的 `_transcript.md` 虽然也是 markdown，
但它是录音的转写附件，混进列表会让人点「笔记」却打开转写。

## 安装

**从索引源安装（推荐）**

1. 打开 DSH 的**插件**页，切到**发现**标签（若没有，先在插件设置里打开「自定义插件索引」）
2. **添加索引源**，填这个地址：`https://magicbaobaoli.github.io/dsh-getnote/index.json`
3. 找到「得到大脑」，点安装

**从 GitHub 直接装**

```sh
dsh plugin --profile <你的 profile> add github:magicbaobaoli/dsh-getnote
```

**本地开发**

```
plugin_manager action:install_bundle target:"<绝对路径>/dsh-getnote"
```

装完重启 DSH，左侧栏出现大脑图标。

## 数据在哪

| 内容 | 位置 |
| --- | --- |
| 笔记 | 设置里的 `vaultRoot`，默认 `$DSH_HOME/dsh-getnote/vault` |
| 设置 | `$DSH_HOME/dsh-getnote.json` |
| 云端凭证（API Key） | `$DSH_HOME/dsh-getnote/cloud.json`（0600） |
| 登录令牌（OAuth） | `$DSH_HOME/dsh-getnote/auth.json`（0600，仅 host 可读） |
| 同步记账 | `$DSH_HOME/dsh-getnote/state.json`（每篇的路径与指纹） |
| 升级备份 | `$DSH_HOME/dsh-getnote/update-backup/<版本>-<时间戳>/`（应用内升级前的旧版） |
| 冲突备份 | `<库根>/.conflicts/`（同名时带 `__cloud-` 前缀的是云端版留档） |
| 回收站 | `<库根>/.trash/` |

`DSH_HOME` 默认是 `~/.dsh`。

## 配置

```yaml
# cordis.patch.yml 里这条插件的 config
- id: dsh-getnote
  name: dsh-getnote
  config:
    vaultPath: 'D:/path/to/your/vault'   # 可选，等价于在设置页里选目录
    apiToken: ''                          # 可选，见下
```

- `vaultPath`：默认笔记库。设置页里选过目录之后以设置页为准。
- `apiToken`：可选。设了之后，**不带 `Origin`/`Referer` 的裸调用**必须带
  `x-getnote-token` 头，否则 403。面板自己的请求（浏览器同源、带 `Origin`）不受影响，
  因为它拿不到 token。默认留空——留空时 curl / 自动化脚本照旧能直接调。

## 边界

- 云端写入只动**你自己的**笔记。不做企业代授权场景的适配。
- 录音卡（GetSeed 硬件）的**云端**专用接口是 fail-closed 的，普通个人账号调用会 403；
  这类笔记走通用笔记接口照样能读能播。
- 录音卡**直连**走蓝牙，需要本机有 Python 3.10+ 与 `bleak`（`pip install bleak`）。
  插件本体仍然零依赖零构建——BLE 那段放在一个独立的 Python 桥里，不连卡的用户不受影响。
  直连只导入音频，不转写。
- 热点快传会临时改本机 WLAN 配置（`netsh wlan add/connect`）。卡片热点没有互联网，
  所以面板上「退出热点」按钮任何时候都能点；这条通道的传输服务端口与路径仍在探测中，
  探到之后面板会把它们摊开显示，但不代你下载。
- 录音类笔记的 ASR 原文原样保留，不做改写。
- 同步是「云端 → 本地」的镜像 + 面板里的显式「推送」。没有自动的双向同步：
  本地文件被外部手改成什么样，插件不会猜你的意图替你回写云端。
- API Key 那条通道用的是得到大脑官方 Open API，**该接口仅对会员开放**；
  会员到期后登录通道可能失效，但已经同步到本地的 Markdown 永远能读。
- 批量操作是「逐篇执行、不整体回滚」：20 篇里 1 篇失败，另外 19 篇照样做完，
  失败的会在结果里列出来，重试只影响那几篇。
- 删目录只允许删**空目录**（既没有 `.md` 也没有子目录）。这条不是保守，是故意的：
  左栏一个右键加一个确认框，误触的概率远高于用户真想把整个目录连内容一起删掉。
- 删标签是「从所有笔记的 frontmatter 里抹掉这个名字」，**笔记本身一篇都不会动**。
- 冲突处理的状态记在 `.conflicts/.resolved.json` 里，跟着库走：整库 zip 导出再导入到
  另一台机器，处理过的冲突仍然是已处理。留档文件本身永不自动删除，随时能退回未处理。
- 版本历史存在库里的 `.history/` 目录，不进笔记列表；它和 `.trash/`、`.conflicts/` 一样
  不会被当成笔记扫描。
